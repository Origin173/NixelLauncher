## 依赖替换

已移除 `@xmcl/core`、`@xmcl/installer`、`@xmcl/modrinth`、`@xmcl/user`、`@xmcl/unzip` 和对应 pnpm 补丁。游戏、加载器、Java、认证和 Modrinth 协议由 Nixel 模块实现，ZIP 使用 `yauzl`/`yazl`。现有实例与插件 ID 保留。

用户先前指定复用的图标、头像属于素材，继续保留来源记录与许可，见 [图标资源](assets.md)。
