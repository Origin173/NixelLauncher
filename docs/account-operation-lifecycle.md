# 账号操作与登录取消

账号删除与 Microsoft、Yggdrasil 刷新按 Host 和账号 ID 串行执行，队列仅覆盖同一身份。删除等待已经开始的刷新结束后清除凭据、账号及引用；排在删除后的刷新重新检查账号存在性，不能重新添加已删除账号。手动刷新、游戏启动和皮肤请求通过同一个 Microsoft `refresh` 实现，不另建调用方锁。刷新保留原账号 ID，并核对返回 Minecraft UUID。

`accounts.microsoft.cancel({ id })` 取消对应设备登录。Host 为每次设备登录持有 AbortController，贯穿令牌交换、Xbox/Minecraft 请求和最终保存。界面关闭（包括保留组件的关闭动画）、切换类型或清除设备码均通知 Host；同一设备登录不并发轮询。到期清理和插件停用也中止在途请求，定时器随插件释放。

凭据写入和账号删除共用账号队列。写入凭据前保存原值；账号状态进入持久化更新回调前再检查取消。取消或状态保存失败时恢复原凭据；此前没有凭据则删除新记录。状态更新回调开始是提交边界：此后已经开始的原子状态写入会完成，取消不会删除已提交的登录。这与停止后续轮询不同，Host 在网络请求及提交前都检查取消状态。

验证使用 `output/account-races-check` 下的临时可控响应，加载实际账号模块，所有 OAuth、Xbox、Minecraft 响应与凭据存储均为隔离假数据，不连接认证服务。覆盖手动刷新、启动会话和皮肤刷新期间删除，删除后陈旧刷新拒绝，等待 Minecraft profile 响应时取消，等待凭据写入时取消，取消重新登录恢复旧凭据，以及插件停用中止提交。临时验证文件不纳入仓库。

Yggdrasil 角色切换提交使用同一个账号队列，进入提交前重新检查原账号和启动占用；刷新在队列内读取当前账号与凭据。角色选择保留 Host pending 项直到请求及提交结束，`accounts.yggdrasil.cancel({ id })` 中止在途选角请求和提交。插件停用、到期及界面关闭也取消选择。已删除账号的在途选角不能重建账号。选角取消或状态写入失败恢复之前的凭据。

删除账号先保留原凭据；状态持久化失败时，在同一账号队列中恢复凭据，避免留下存在于状态中却无法登录的账号。额外隔离验证覆盖 Yggdrasil 刷新与删除、删除后陈旧刷新、选角网络响应及凭据写入期间取消、选角期间移除账号，以及移除账号的状态写入失败。
